# ColegaDeCena V3

AI rehearsal tool for actors and screenwriters.

Purpose:
Allow actors to rehearse scenes using AI voices.

Main features:

1 Script upload
FDX
PDF
TXT

2 Script parsing
Extract:
Characters
Dialogue
Scene headings
Action lines

3 Actor Mode
User selects one character.
AI reads all other characters.

4 Voice system
Uses ElevenLabs API.
User must provide their own API key.
