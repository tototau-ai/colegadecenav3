# ColegaDeCena V3

AI rehearsal tool for actors and screenwriters.

Upload a script, choose a character, and rehearse scenes with AI voices.

Main goals

- Read screenplays
- Detect characters automatically
- Allow actor rehearsal mode
- Generate voice reading using ElevenLabs
- Never store scripts on the server
